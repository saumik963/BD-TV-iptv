# 📺 BD-TV

A modern, fast, and responsive Live TV streaming web application built with React, TypeScript, and HLS.js. BD-TV allows users to watch live television channels directly from M3U playlists with a clean, user-friendly interface optimized for desktop and mobile devices.

## 🌐 Live Demo

🔗 https://old-breeze-915c.jemswyen.workers.dev/

---

## ✨ Features

- 📡 Live TV streaming using M3U playlists
- 🎬 Built-in HLS.js video player
- 🔍 Real-time channel search
- 🗂️ Channel category filtering
- ❤️ Favorite channels support
- 🕒 Recently watched channels
- 📱 Fully responsive design
- 🌙 Modern dark theme UI
- 🖥️ Fullscreen viewing mode
- 🎹 Keyboard shortcuts support
- ⚡ Fast channel switching
- 💾 Local storage persistence
- 🎯 Mobile-friendly experience

---

## 🎹 Keyboard Shortcuts

| Key | Action |
|------|---------|
| Space | Play / Pause |
| F | Toggle Fullscreen |
| M | Mute / Unmute |
| ↑ | Increase Volume |
| ↓ | Decrease Volume |
| ← | Previous Channel |
| → | Next Channel |

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/saumik963/BD-TV-iptv.git
cd bd-tv
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## 📡 M3U Playlist Support

BD-TV dynamically loads channels from M3U playlists and automatically extracts:

- Channel Name
- Channel Logo
- Category
- Stream URL
- Metadata

Simply configure your M3U playlist source and the application will generate the channel directory automatically.
